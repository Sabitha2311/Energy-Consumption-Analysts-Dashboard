# Energy Consumption Analytics Dashboard

A professional **Power BI Dashboard for Energy Consumption Analysis**, designed to analyze and visualize **Water, Gas, and Electricity consumption** across buildings and cities.

This project provides an interactive dashboard to monitor consumption patterns, compare resource usage, identify high-consumption areas, and generate meaningful insights using **Microsoft Power BI, Power Query, and DAX**.

## Overview

The Energy Consumption Analytics Dashboard transforms raw consumption data into interactive and easy-to-understand visualizations.

The dashboard focuses on three major resources:

* 💧 **Water Consumption**
* 🔥 **Gas Consumption**
* ⚡ **Electricity Consumption**

Users can interact with the dashboard using slicers, navigation buttons, and page-level filters to explore consumption data based on **Date, Year, Building, and City**.

## Highlighted Features

### 1. Data Transformation with Power Query

Raw energy consumption data is cleaned and transformed using **Power Query** before creating the dashboard.

Key activities include:

* Removing unnecessary columns
* Handling missing values
* Changing data types
* Data cleaning and formatting
* Creating calculated columns
* Preparing data for analysis

### 2. Data Modeling

A structured data model is created in Power BI to support efficient analysis.

The model allows relationships between relevant tables and helps in creating reliable reports and calculations.

### 3. DAX Measures

Several DAX measures are created to calculate important consumption metrics such as:

* Total Consumption
* Average Consumption
* Maximum Consumption
* Minimum Consumption
* Total Buildings
* Resource-wise consumption

### 4. Interactive KPI Cards

The dashboard includes KPI cards to provide a quick overview of important metrics.

**Water Dashboard:**

* Total Water Consumption
* Average Water Consumption
* Maximum Water Consumption
* Minimum Water Consumption
* Total Buildings

**Gas Dashboard:**

* Total Gas Consumption
* Average Gas Consumption
* Maximum Gas Consumption
* Minimum Gas Consumption
* Total Buildings

**Electricity Dashboard:**

* Total Electricity Consumption
* Average Electricity Consumption
* Maximum Electricity Consumption
* Minimum Electricity Consumption

### 5. Water Consumption Analysis

The Water page provides detailed insights into water usage.

It includes:

* Water consumption trend
* Building-wise consumption
* Monthly consumption
* Daily consumption
* Consumption distribution
* Interactive filters

### 6. Gas Consumption Analysis

The Gas page focuses on identifying gas consumption patterns.

It includes:

* Gas consumption trends
* Building-wise gas usage
* Monthly analysis
* Daily analysis
* Gas consumption distribution
* Interactive filters

### 7. Electricity Consumption Analysis

The Electricity page provides insights into electricity usage and consumption trends.

It includes:

* Electricity consumption trend
* Building-wise analysis
* Monthly electricity usage
* Daily electricity usage
* Consumption comparison
* Interactive filters

### 8. Interactive Navigation

A professional navigation system is implemented using:

* Page Navigator
* Navigation Buttons
* Bookmarks
* Page-level navigation

Users can easily navigate between:

**Overview → Water → Gas → Electricity**

### 9. Interactive Filters

The dashboard provides slicers to dynamically analyze the data based on:

* Date
* Year
* Building ID
* City

Changing a filter automatically updates the dashboard visuals and KPI values.
